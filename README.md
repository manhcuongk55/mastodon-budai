## 🦀 HCRAB: Human Consensus Reputation Algorithm

> **"Trong Internet tương lai: Không phải ai quảng cáo to nhất sẽ thắng, mà ai được nhiều người thật xác nhận nhất sẽ thắng."**

**CRAB = Claim → Reference → Authentication → Broadcast**

1. **C (Claim):** A brand submits a marketing claim.
2. **R (Reference):** The system isolates verified users who have proximity or historical relevance.
3. **A (Authentication):** Users provide Zero-Knowledge evidence (photos, reviews) confirming the claim.
4. **B (Broadcast):** Once verified, the claim is broadcasted with a public TrustScore.

**The TrustScore Formula:**
`TrustScore = user_trust × experience_proof × proximity`

*(High marketing + Low real user proof = Fake marketing suspicion)*

## 🚀 Quick Start

### 1. Clone
```bash
git clone https://github.com/manhcuongk55/mastodon-budai.git
cd mastodon-budai
```

### 2. Setup (macOS)
```bash
brew install rbenv node redis postgresql
rbenv install 3.3.6 && rbenv global 3.3.6
corepack enable && yarn install
bundle install
```

### 3. Database
```bash
RAILS_ENV=development bin/rails db:setup
```

### 4. Run
```bash
# Terminal 1: Backend
RAILS_ENV=development bin/rails s -b 0.0.0.0

# Terminal 2: Frontend  
yarn dev

# Terminal 3: P2P Node
node smile_trust_node.js

# Terminal 4: Jobs
RAILS_ENV=development bundle exec sidekiq
```

### 5. Contribute with AI
Open VS Code → Install **Antigravity** extension → Start coding with AI!
