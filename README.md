## 🪷 What is MAKAI?

MAKAI is a social network for **real people only**.

No email. No password. No hidden tracking.  
**Just a genuine smile.**

In a world full of bots, spam, fake accounts, and AI-generated content,  
MAKAI solves this with:

| Step | How |
|------|-----|
| 😊 **Smile Identity** | Your genuine smile becomes your identity |
| 🤝 **P2P Verification** | Two real people confirm you are real |
| ✅ **Trust Score** | Verified by real humans, not algorithms |

**MAKAI = Human-first Network.**

## 🏴‍☠️ Three Signals, Not Likes

On MAKAI there are only three signals:

| Signal | Meaning |
|--------|---------|
| ✅ **Trust** | Highlight good actions, trustworthy people |
| 🛡️ **Safe** | Peaceful content, supportive environment |
| ❌ **Fake** | Identify misinformation, correct mistakes |

Not likes. Not followers. Not algorithms.  
**Just truth between real people.**

## 🚀 Quick Start with AI (Antigravity)

Anyone can contribute to MAKAI using AI tools:

### 1. Clone
```bash
git clone https://github.com/manhcuongk55/mastodon-budai.git
cd mastodon-budai
```

### 2. Setup (macOS)
```bash
brew install rbenv node redis postgresql
rbenv install 3.3.6 && rbenv global 3.3.6
corepack enable && yarn install
bundle install
```

### 3. Database
```bash
RAILS_ENV=development bin/rails db:setup
```

### 4. Run
```bash
# Terminal 1: Backend
RAILS_ENV=development bin/rails s -b 0.0.0.0

# Terminal 2: Frontend  
yarn dev

# Terminal 3: Jobs
RAILS_ENV=development bundle exec sidekiq
```

### 5. Contribute with AI
Open VS Code → Install **Antigravity** extension → Start coding with AI!

```
Tell AI: "Add a new feature to MAKAI that..."
AI will: understand codebase → write code → test → commit
```
